# Azure ExpressRoute Campus Design

## Project Overview

This project demonstrates the design and configuration of
Azure ExpressRoute connectivity for a university campus.

## Objectives

- Establish connectivity between the campus network and Microsoft Azure
- Configure an ExpressRoute circuit
- Create an Azure Virtual Network
- Configure a Virtual Network Gateway
- Configure the required public IP resource
- Demonstrate the Azure network architecture

## Azure Resources

- Resource Group: Campus-ExpressRoute-RG
- ExpressRoute Circuit: Campus-ExpressRoute-Circuit
- Virtual Network: Campus-VNet
- Virtual Network Gateway: Campus-ExpressRoute-Gateway
- Public IP: Campus-ER-Gateway-PIP

## Architecture

University Campus
        |
        ↓
   ExpressRoute
        |
        ↓
Azure Virtual Network
        |
        ↓
Virtual Network Gateway
